The Inventory Management System is a Python-based application integrated with an SQLite3 database to simplify and organize inventory management. It allows users to register and log in as Admin or Staff, with different functionalities based on their roles. The system enables product addition, viewing, updating, deletion, and searching by product name or category. It also maintains transaction records, including transaction types, quantities, and dates, to track changes made to the inventory. This project aims to provide a simple and efficient way to manage product details while demonstrating the practical application of Python programming and database management.
